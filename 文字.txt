                                </div>
                            </li>

                                    <p class="text-sm text-stone-600">重視理性思考 (rational thinking) 和探索精神 (spirit of inquiry)，不再盲目相信權威，質疑傳統及教會教導，追求突破創新。</p>
                                </div>
                            </li>

                                <h4 class="font-bold text-stone-900 mt-2">Decline of Feudal Society (封建社會瓦解)</h4>
                                <p class="text-sm text-stone-600 mt-1">城鎮興起與黑死病 (Black Death) 削弱封建制度。農奴 (serfs) 離開莊園成為自由市民 (free townspeople)，獲得更多自由與時間投入藝術與學術。</p>

                            <div class="p-4 bg-white rounded-xl border border-stone-200 shadow-sm">
                                <span class="text-xs font-bold px-2 py-1 bg-amber-100 text-amber-800 rounded">成因 2</span>
                                <h4 class="font-bold text-stone-900 mt-2">Classical & Islamic Civilisations (古希羅與伊斯蘭文明刺激)</h4>
                                <p class="text-sm text-stone-600 mt-1">阿拉伯穆斯林保留了古希羅典籍。11-13世紀十字軍東征 (Crusades) 促進歐亞知識交流，拓寬視野並重新燃起古希羅文化興趣。</p>
                            </div>
                            <div class="p-4 bg-white rounded-xl border border-stone-200 shadow-sm">
                                <span class="text-xs font-bold px-2 py-1 bg-amber-100 text-amber-800 rounded">成因 3</span>
                                <h4 class="font-bold text-stone-900 mt-2">Rise of Wealthy City-States (富有城邦與新興階層)</h4>
                                <p class="text-sm text-stone-600 mt-1">意大利城邦成為貿易樞紐。商人 (merchants) 和銀行家 (bankers) 形成新社會階層，追求世俗生活 (secular life)，透過資助藝術家來提升家族地位。</p>
                            </div>
                            <div class="p-4 bg-white rounded-xl border border-stone-200 shadow-sm">
                                <span class="text-xs font-bold px-2 py-1 bg-amber-100 text-amber-800 rounded">成因 4</span>
                                <h4 class="font-bold text-stone-900 mt-2">Rise of Universities (大學興起與學者西逃)</h4>
                                <p class="text-sm text-stone-600 mt-1">12世紀起大學興起提供學術自由；14世紀東羅馬帝國動盪，學者攜帶大量古希羅手稿逃往意大利，保存在大學中。</p>
                            </div>
                        </div>
                        <div class="p-4 bg-white rounded-xl border border-stone-200 shadow-sm">
                            <span class="text-xs font-bold px-2 py-1 bg-amber-100 text-amber-800 rounded">成因 5</span>
                            <h4 class="font-bold text-stone-900 mt-2">Decline of Church Authority (教會權威下降)</h4>
                            <p class="text-sm text-stone-600 mt-1">歐洲人發現教會教義有誤，加上十字軍東征失敗，教會影響力大不如前。君主拒絕繳税，促使人們擺脫宗教控制，探索人的價值。</p>

                btnElement.classList.add('bg-green-100', 'border-green-500', 'text-green-900');

                feedback.innerHTML = `<strong><i class="fa-solid fa-circle-check"></i> 正確！</strong> ${item.explanation}`;

                btnElement.classList.remove('bg-white', 'border-stone-200');
                btnElement.classList.add('bg-red-100', 'border-red-500', 'text-red-900');

        // Gemini AI Chatbot Logic
        async function handleSendChat() {
            const input = document.getElementById('chat-input');
            const prompt = input.value.trim();
            if (!prompt) return;

            addChatMessage('user', prompt);
            input.value = '';

            const loadingId = addChatMessage('bot', '<i class="fa-solid fa-spinner fa-spin"></i> AI 導師思考中...');

            try {
                const systemPrompt = "你是一位精通中學歷史科（ Topic 5: 文藝復興與宗教改革 Renaissance & Reformation）的專業老師。請根據筆記內容，用親切、清晰、繁體中文回答學生的問題。包含重點條列，有助於考試復習。";
                const apiKey = ""; // Canvas runtime automatically supplies key if empty
                const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-flash-preview:generateContent?key=${apiKey}`;

                const response = await fetch(apiUrl, {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({
                        contents: [{ parts: [{ text: prompt }] }],
                        systemInstruction: { parts: [{ text: systemPrompt }] }
                    })
                });

                const data = await response.json();
                const reply = data.candidates?.[0]?.content?.parts?.[0]?.text || "抱歉，目前無法取得 AI 回應。";

                updateChatMessage(loadingId, reply.replace(/\n/g, '<br>'));
            } catch (err) {
                updateChatMessage(loadingId, "⚠️ 連線發生錯誤，請稍後再試。");
            }
        }

        function sendQuickPrompt(text) {
            document.getElementById('chat-input').value = text;

        }

        function addChatMessage(role, text) {
            const container = document.getElementById('chat-messages');
            const msgDiv = document.createElement('div');
            const id = 'msg-' + Date.now();
            msgDiv.id = id;
            msgDiv.className = `flex items-start space-x-3 ${role === 'user' ? 'justify-end' : ''}`;

            if (role === 'user') {
                msgDiv.innerHTML = `
                    <div class="bg-amber-600 text-white p-3 rounded-2xl rounded-tr-none shadow-sm max-w-[80%]">${text}</div>
                    <div class="w-8 h-8 rounded-full bg-stone-700 text-white flex items-center justify-center font-bold text-xs shrink-0"><i class="fa-solid fa-user"></i></div>
                `;
            } else {
                msgDiv.innerHTML = `
                    <div class="w-8 h-8 rounded-full bg-amber-600 text-white flex items-center justify-center font-bold text-xs shrink-0"><i class="fa-solid fa-robot"></i></div>
                    <div class="bg-white p-3 rounded-2xl rounded-tl-none border border-stone-200 shadow-sm text-stone-800 max-w-[80%]">${text}</div>
                `;
            }

            container.appendChild(msgDiv);
            container.scrollTop = container.scrollHeight;
            return id;
        }

        function updateChatMessage(id, newHtml) {

            }
